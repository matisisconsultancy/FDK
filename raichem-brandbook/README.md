# RAICHEM · Brand Book — Entregable web interactivo

Versión navegable e interactiva del **RAICHEM Brand Book v1.0** (Matisis Consultancy, 2026),
construida fielmente sobre el propio sistema de marca definido en el documento.

## Contenido

| Archivo | Descripción |
|---|---|
| `index.html` | Estructura completa: los 12 capítulos + portada y cierre |
| `brandbook.css` | Sistema visual de Raichem (color, tipografía, grid blueprint, brackets, ticks) |
| `brandbook.js` | Interacciones: scroll-spy, barra de progreso, copia de color, checklist persistente, animaciones |

## Características interactivas

- **Navegación lateral con scroll-spy** — resalta el capítulo activo mientras se lee.
- **Barra de progreso de lectura** en la parte superior.
- **Paleta cromática interactiva** — clic en cualquier color copia el HEX al portapapeles.
- **Specimens tipográficos** reales (Saira Condensed · Archivo · IBM Plex Mono vía Google Fonts).
- **Matriz de buyer personas** y tablas de mensajes por industria.
- **Checklist de aprobación (14 puntos)** — marcable, con progreso circular que se guarda en el navegador.
- **Animaciones de aparición** al hacer scroll y **100 % responsive** (móvil / tablet / desktop).

## Sistema de marca respetado

- **Colores:** Rosso Raichem `#C91517` (acento), Nero `#1A1A1A`, Grigio `#666666`, Grigio chiaro `#F2F2F2`, Bianco `#FFFFFF`.
- **Tipografía:** Saira Condensed (display 700–900), Archivo (texto 400–700), IBM Plex Mono (datos/labels 400–600).
- **Sistema gráfico:** grid blueprint 96px, corner brackets, tick rojos, números fantasma, labels técnicos en mono.

## Cómo verlo

Abrir `index.html` en cualquier navegador moderno. No requiere build ni servidor.

## Publicación (GitHub Pages)

El repositorio ya está preparado para Pages (`.nojekyll`). Una vez activado Pages sobre la rama,
el entregable queda accesible en:

```

```
