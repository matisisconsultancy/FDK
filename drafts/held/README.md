# Held drafts

Notes sent through Telegram between mid-September and October 12, 2026 that
never went online: their title gave the same address as a note already
published ("Daily Update", "The Next Economy Research Centre", …), so the
publisher refused them while the bot linked the old note.

That is fixed (a new note with a recurring title now gets the date in its
address). These drafts are kept here, untouched, until the editor decides
whether to publish them. drafts/held/ is not read by the publisher; to
publish one, move it back to drafts/.
