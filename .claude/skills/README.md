FDK EmpowerNet home, the book pages); taste-skill for new pages or a new
visual direction; impeccable for audit / polish / typography / animation.
Brand rules that override any generic advice in them: FDK EmpowerNet is
green (#2ee06a); only The Velocity Edge uses the sky blue (#309bff).
